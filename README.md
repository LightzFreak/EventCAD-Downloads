# EventCAD Downloads

Public application downloads for EventCAD. The application source remains private.

No update-capable release has been published yet. Signed macOS releases will appear under Releases when ready.

## macOS updates

Install the first update-capable DMG manually. Later versions can be checked from **Einstellungen → Nach Updates suchen** in EventCAD.

Downloads are provided for Apple Silicon Macs. Update installation requires saving the current project before restarting.
